# 0.4.0 — 2026-11-26

### Fonctionnalités

- (30) Intègre les pratiques Claude Code / agentic coding de fin 2026, vérifiées dans la doc
  officielle (versions minimales citées quand la doc les donne) :
  - rule `verification.md` : un check pass/fail comme critère de fin, en quatre niveaux (consigne,
    `/goal`, hook `Stop`, relecteur en contexte vierge), preuve par la sortie de commande ;
  - rule `session-management.md` : une session par chantier, plan mode, interview → `SPEC.md` →
    nouvelle session, `/rewind` et checkpoints, `/btw`, compaction ;
  - rule `permissions.md` : modes (auto, dontAsk…), règles allow/ask/deny, règle « jamais » posée
    en règle plutôt qu'en permission absente, sandbox, usage sans surveillance ;
  - rule `parallel-work.md` : worktrees, `/batch`, boucle `claude -p` testée sur 2-3 fichiers
    d'abord, sortie JSON pour la CI ;
  - prompt `spec-interview` et agent `plan-compliance-reviewer` (écarts de correction ou
    d'exigences uniquement, jamais le style) ;
  - `context-efficiency.md` (sous-agents choisis selon le volume lu, `CLAUDE.md` minimal, ce que le
    modèle voit), `hooks.md` (gabarit `Stop` bloquant), `mcp.md` (CLI avant MCP) ;
  - `start-ticket` : commande de vérification dans le plan, tests ciblés en arrière-plan, session
    vierge après le plan, revue du diff avant commit.
- (30) Settings du repo : permission demandée avant chaque `git commit`, `git push` et
  `gh pr merge`, au lieu de bloquer ou de s'en remettre à une permission absente.
