# Qualification

| Travail demandé | Résultat |
|---|---|
| valeur utilisateur/partie prenante livrable indépendamment | Story |
| valeur répartie sur plusieurs tranches | plusieurs candidats Story séparés |
| autre chose | pas une Story |

Une incertitude à l'intérieur d'un résultat de valeur bloque sa Story ; elle ne la remplace pas
(voir `evaluer` pour la gestion du blocage).
