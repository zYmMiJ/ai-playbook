# Docs par module

Une fiche par module/écran/composant partagé = une règle métier ou un piège technique
**spécifique à ce module**, qui ne mérite pas sa place dans `architecture/overview.md` (trop
transverse pour ça) ni dans `decisions/` (pas rattaché à un ticket précis, ou plus un rappel
permanent qu'une décision).

Aucune fiche pour l'instant — à créer au fil de l'eau, notamment via le skill `start-ticket`.

Convention de nommage : `<nom-du-module-ou-composant>.md`, en minuscules-avec-tirets.
